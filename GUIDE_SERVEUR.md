# Guide Mode Serveur Mobile

## Accès à l'interface mobile

### Option 1 : Via l'application principale
1. Connectez-vous à l'application RestoBar
2. Allez dans "Interface serveur"
3. Cliquez sur le bouton "Activer" dans la section "Mode Mobile Serveur"
4. L'interface mobile s'ouvre en plein écran

### Option 2 : Page dédiée smartphone
1. Ouvrez `votre-domaine.com/serveur.html` sur votre smartphone
2. Suivez les instructions pour accéder à l'application
3. Activez le mode mobile une fois connecté

## Utilisation de l'interface mobile

### 1. Sélection de table
- À l'ouverture, vous voyez toutes les tables disponibles
- Les tables occupées sont grisées
- Cliquez sur une table disponible pour commencer

### 2. Prise de commande
- **Filtres de catégories** : Utilisez les boutons en haut pour filtrer par catégorie
- **Ajout de produits** : Appuyez sur un produit pour l'ajouter au panier
- **Panier** : Le bouton en haut à droite affiche le nombre d'articles

### 3. Gestion du panier
- Appuyez sur l'icône panier pour voir votre commande
- **+/-** : Modifiez les quantités
- **X** : Supprimez un article
- **Vider** : Vide tout le panier
- **Envoyer** : Envoie la commande à la cuisine/bar

### 4. Validation
- Après l'envoi, une confirmation s'affiche
- La commande est envoyée automatiquement aux imprimantes configurées
- Le panier se vide automatiquement
- Vous pouvez sélectionner une nouvelle table

## Fonctionnement

### Flux de travail
1. **Serveur** : Prend la commande sur smartphone
2. **Système** : Envoie automatiquement à la cuisine/bar
3. **Cuisine/Bar** : Reçoit et prépare la commande
4. **Client** : Demande l'addition au serveur
5. **Caisse** : Gère le paiement au comptoir

### Avantages
- Interface tactile optimisée
- Prise de commande rapide
- Envoi instantané à la cuisine/bar
- Pas de manipulation de caisse pour les serveurs
- Réduit les erreurs de commande

## Configuration pour smartphone

### Ajouter à l'écran d'accueil (PWA)
#### Sur iPhone (Safari)
1. Ouvrez l'application
2. Appuyez sur l'icône de partage
3. Sélectionnez "Sur l'écran d'accueil"
4. Nommez le raccourci "RestoBar Serveur"

#### Sur Android (Chrome)
1. Ouvrez l'application
2. Menu ≡ → "Ajouter à l'écran d'accueil"
3. Confirmez l'ajout

### Conseils d'utilisation
- Utilisez en mode portrait pour une meilleure ergonomie
- Gardez le smartphone chargé pendant le service
- Vérifiez la connexion WiFi avant de commencer
- Utilisez un étui antichoc pour protéger le smartphone

## Gestion des problèmes

### La commande ne s'envoie pas
- Vérifiez votre connexion internet
- Assurez-vous que le panier n'est pas vide
- Vérifiez qu'une table est sélectionnée

### Impossible de sélectionner une table
- La table est peut-être occupée
- Retournez à l'écran d'accueil et réessayez

### Le panier ne se met pas à jour
- Rafraîchissez la page
- Reconnectez-vous si nécessaire

## Sécurité

- Chaque serveur a son propre code d'accès
- Les serveurs ne peuvent pas accéder aux fonctions de caisse
- Les serveurs ne voient pas les prix d'achat
- Toutes les actions sont tracées pour le reporting

## Support

Pour toute question ou problème :
- Contactez le gérant
- Consultez les paramètres de l'application
- Vérifiez la configuration des imprimantes
